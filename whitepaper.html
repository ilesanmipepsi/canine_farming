CANINE FARMING

Official Whitepaper • Version 1.2

Sustainable Proof-of-Stake Simulation on Pi Network

1. Abstract

The Canine Farming Protocol is a community-driven, gamified Proof-of-Stake simulation built exclusively for the Pi Network ecosystem. Drawing inspiration from the sustainable and exponential growth patterns of German Shepherd populations, the protocol introduces a strictly hard-capped utility token — $CFM — with a maximum supply of 10,000,000 tokens.

It aims to educate Pioneers on responsible tokenomics while providing an engaging, transparent, and fair simulation environment.

2. Core Protocol Mechanics

  • Single-Entry Activation: A one-time 0.5 Pi payment ensures fair access and prevents multi-accounting.
  • Initial Seed Balance: Every successfully activated pioneer receives exactly 0.000025 $CFM.
  • Anti-Whale Mechanism: Hard cap of 1.0 $CFM per wallet. Once reached, the wallet is permanently removed from the reward pool to protect fairness for new pioneers.

3. Tokenomics

Total Maximum Supply: 10,000,000 $CFM (immutable hard cap)

  • Initial Circulating Supply: 250 $CFM
  • Staking & Rewards Pool: 9,999,750 $CFM
Early Growth Phase: +400% Annual Expansion
Final Phase: 156% Terminal Adjustment to exhaust reward pool

4. Governance & Development

The project is currently developed and maintained by a single dedicated developer to ensure speed, security, and full compliance during the Testnet phase.

Upon achieving key milestones and Mainnet readiness, the protocol plans to evolve toward decentralized community governance, giving verified Pioneers meaningful input on future direction.

5. Privacy & Data Policy

  • Only Pi Network username is collected via the official Pi SDK.
  • No real names, emails, phone numbers, or wallet passphrases are ever requested or stored.
  • All data is handled with Row Level Security and best privacy practices.

Important Disclaimer

Canine Farming Protocol is a gamified educational simulation. $CFM is an internal calculation metric for entertainment and learning purposes within the Pi Network. It does not constitute financial investment, equity, or guaranteed returns.
