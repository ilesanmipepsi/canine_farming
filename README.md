# Canine Farming Protocol

**Sustainable Growth • Capped Supply • Community-Driven**

### About the Project
Canine Farming Protocol is a revolutionary Proof of Stake ecosystem inspired by the exponential yet sustainable growth pattern of the German Shepherd dog population. 

- **Maximum Supply**: 10,000,000 $CFM (hard cap)
- **Initial Distribution**: 250 $CFM distributed to early pioneers
- **Entry**: Only $10 maximum per pioneer
- **Anti-Whale Mechanism**: Wallets reaching 1 $CFM are automatically removed from reward pool
- **Vision**: Build a major Centralized Exchange (CEX) where token holders become ecosystem shareholders

### Tech Stack
- Frontend: HTML + Vanilla JavaScript + Pi Network SDK
- Backend: Node.js + Express
- Hosting: Vercel
- Blockchain: Pi Network
