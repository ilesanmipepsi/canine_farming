CANINE FARMING

Official Protocol Whitepaper

Version 1.1 • Ecosystem Utility Tokenomics

1. Abstract

The Canine Farming Protocol is a community-first, decentralized simulation application built inside the Pi Network ecosystem. Inspired by the organic, controlled, and sustainable population growth patterns observed in specialized German Shepherd breeding, the protocol introduces a strictly hard-capped utility asset, $CFM, limited to a maximum supply of 10,000,000 units.

By leveraging the Pi Browser architecture, the platform provides Pioneers with an interactive environment to engage with advanced gamified Proof-of-Stake (PoS) models, fostering non-speculative utility, tokenomics engineering education, and Web3 financial literacy.

2. Core Protocol Mechanics

To ensure absolute alignment with the Pi Core Team’s developer guidelines, the platform enforces a strict single-entry initialization framework:

  • Ecosystem Activation Fee: A fixed, one-time platform access transaction of 0.5 Pi (Test-Pi during the Testnet testing phase) is required to initialize an active node instance. Multi-accounting onboarding loops and duplicate wallet registrations are programmatically blocked by the protocol.
  • Baseline Seed Allocation: Upon successful on-chain transaction validation from the Pi SDK, the backend provisions an initial seed balance of exactly 0.000025 $CFM directly to the Pioneer's interactive simulation wallet.

3. Tokenomics & Asymmetric Supply Squeeze

The total asset matrix of 10,000,000 $CFM tokens is structurally divided to protect the stability and allocation metrics of long-term ecosystem participants:

  • Initial Active Base Supply: 0.000025 $CFM × 10,000,000 Max Pioneers = 250 $CFM.
  • Unminted Staking Rewards Pool: 9,999,750 $CFM.

Supply Expansion Curve

The system utilizes an automated expansion timeline designed to distribute rewards safely to active, qualified accounts without inducing hyper-inflationary block crashes:

Yearly Expansion = Circulating Supply + 400%

The protocol expands global circulation by 400% annually for the opening lifecycle phases. During the ultimate year of the unminted reward pool's lifespan, the remaining supply undergoes a terminal liquidation adjustment of 156% to exhaust the staking reserves fully and transition the app into a fully self-sustaining economy.

The 1.0 $CFM Hard Anti-Whale Cutoff

To maximize decentralization and prevent systemic wealth concentration, individual wallets are capped at a strict lifetime limitation:

Max Wallet Capacity = 1.00000000 $CFM

Because Pioneers activate their farming nodes at entirely different time intervals, reward distribution occurs asynchronously. The moment an individual account balance accumulates to exactly 1.0 $CFM, the node is automatically flagged by the protocol and permanently disconnected from the active rewards stream. This preserves the remaining pool blocks specifically for newly arriving Pioneers.

4. Technical Architecture

Canine Farming Protocol implements a low-overhead, serverless configuration optimized for concurrent global mobile network traffic:

  • Frontend Client: Valid HTML5, custom utility CSS, and native JavaScript paired with the Pi Network JavaScript SDK (v2.0). Real-time token tickers calculate balances client-side using millisecond interval processing to preserve device resource states.
  • Backend Cloud Engine: Stateless Node.js microservices hosted on Vercel's high-speed global edge network.
  • Data Layer Optimization: Cloud asset states are preserved via serverless-friendly HTTP REST requests. This structure prevents connection pooling drops or gateway execution timeouts during intensive transactional validation events.
